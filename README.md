## Cómo abordo un análisis

1. Defino la pregunta y la unidad de análisis.
2. Reviso calidad, cobertura y coherencia de los datos.
3. Exploro patrones y contrasto interpretaciones.
4. Comunico resultados, limitaciones y próximos pasos.
